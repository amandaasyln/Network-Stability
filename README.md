## ✨ Features

-  Realtime network speed testing
-  QoS parameter monitoring
-  LSTM-based network stability classification
-  Interactive monitoring dashboard

##  Dataset 

| Feature | Description |
|----------|------------|
| Ping | Network latency (ms) |
| Download | Download speed (Mbps) |
| Upload | Upload speed (Mbps) |
| Packet Loss | Packet loss percentage (%) |
| Jitter | Delay variation (ms) |
| Status | Stable / Unstable |
